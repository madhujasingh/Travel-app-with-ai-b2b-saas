Annual Multi Trip Insurance provides coverage for unlimited trips
taken during a 12-month period. Allows one-time purchase for a year,
avoiding repetitive policy buying.

2 new plans!!
  - TripSafe Titanium Annual ($500,000 Cover).

  "ict": "amt"

  - Region will have the 2 options: Worldwide(WW) and Worldwide excl
    US & Canada(XUSC)

AMT Search API - Sample Request Payload:

{
  "isq": {
    "sd": "2025-12-20",
    "ed": "2026-12-19",
    "isc": {
      "iri": [
        { "rkey": "MDE", "rt": "POPULARREGION" },
        { "rkey": "EUR", "rt": "POPULARREGION" },
        { "rkey": "SCH", "rt": "POPULARREGION" },
        { "rkey": "ASI", "rt": "POPULARREGION" }
      ]
    },
    "iti": [
      { "age": 4 }
    ],
    "isef": false,
    "ict": "AMT",
    "adr": "45"
  }
}

  [note: "sd"/"ed" here span a full year (2025-12-20 to 2026-12-19 =
  exactly 365 days) - consistent with the "12-month period" framing,
  not the 30/45/60/90-day one. "adr" reappears from the Standalone
  flow (seen in Part 3/4) - never fully explained there either; still
  unconfirmed what it stands for.]

Request Verbose:
  sd    Start date of the insurance coverage (format: YYYY-MM-DD).
  ed    End date of the insurance coverage (format: YYYY-MM-DD).
  isc   Insurance search criteria, which includes region information.
    iri : Region details where the insurance will be applicable
      rkey : Name of the region (e.g., "Europe", "Asia", "India", "USA")
      rt : Type of region (e.g., "Country", "Continent")
    iti : List of travelers for whom the insurance search is being
          performed, for the search API we require only age
      Age: Age of the traveler.
