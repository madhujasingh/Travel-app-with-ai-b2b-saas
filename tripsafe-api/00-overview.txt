1. INTRODUCTION (p.4)
======================================================================
TripSafe is a new travel insurance product covering travellers on
INTERNATIONAL trips. Offered in 4 "journeys" (integration modes):

  - Embedded   - API clients can offer to purchase travel insurance at
                 the time of FLIGHT booking (tied to a TripJack flight
                 booking).
  - Standalone - API clients can offer insurance purchase unlinked to
                 any booking on the TJ portal.
  - Student    - Travel insurance plans specifically for students
                 travelling abroad for education, over a longer
                 duration.
  - AMT        - TripSafe Annual Multi-Trip: covers UNLIMITED trips
                 per year, each trip up to a specified max duration
                 (30/45/60/90 days).

TripSafe API: REST over HTTPS, JSON, SSL-secured. Same shared-apikey-
header model as every other TripJack product here (Flights, Hotels,
Cabs): all steps (search -> review -> booking) use api key header
"apikey".

  API-KEY - your sandbox or production API key.

NOTE: if an API key already exists, reuse it. Use the assigned key in
the request header as "apiKey". Contact support for production access.

STEPS TO WHITELIST IP AND GENERATE API KEY (p.5-6)
----------------------------------------------------------------------
Same account-portal flow as Cabs (see cabs-api/cab-api-doc.txt) -
literally the same "API Configuration" left-nav screen, same account.
1. Navigate to User Detail for the User id you want an API key for.
   - Find "API Configuration" on the left nav.
2. Fill IP Address and Email:
   - Provide a valid IPv4 address and a contact email.
   - Click "Update" to save.
3. Generate API Key:
   - Select the APIs you intend to use from the available list.
   - Click "Save" to confirm selection.
   - A new API Key is generated automatically once saved.

2. SERVICE DEFINITION (p.7)
======================================================================
UAT Environment  - Domain: https://apitest.tripjack.com
Production Environment - Domain: https://tripjack.com
  (NOTE: this is the SAME production domain literally listed in the
  Cabs doc, which I confirmed live actually responds with real JSON API
  errors, not a marketing homepage - see project_tripjack_cabs_integration
  memory. So this production domain is plausibly correct/real, just
  not accessible with a key that hasn't been enabled for the product.)

Endpoints Overview Summary:
  API Name              Method  Endpoint                                          Purpose
  Search API            POST    /insurance/v1/searchquery-list                    Fetch available insurance plans
  Review API            POST    /insurance/v1/review                              Plan selection & premium calculation
  Booking API           POST    /oms/v1/insurance/book                            Finalize insurance booking
  Booking Details API   POST    /oms/v1/insurance/booking-details                 Retrieve completed booking details
  Raise Amendment API   POST    /oms/v1/ins/amendment/raise                       Raise amendment request
  Cancellation API      POST    /oms/v1/ins/amendment/confirm-insurance-cancellation  Confirm booking cancellation

  (NOTE: unlike Cabs (mixed GET/POST) and Flights, every TripSafe
  endpoint listed here is POST, including Booking Details itself.)
