🛡️ TripSafe API – Global Travel Insurance & Assistance

What is TripSafe?

TripSafe is a comprehensive travel protection solution that addresses a wide range of travel-related contingencies through 30+ insurance and assistance benefits, including:

Travel Insurance powered by Aditya Birla Health Insurance for unexpected medical expenses

Coverage for adventure sports activities

Passport loss and mugging protection

Complimentary eSIM valid across 175 countries, including 500MB of free data in 72 countries for every traveller

Complimentary baggage protection and tracking through Blue Ribbon Bags for the entire travelling group (worth ₹330 per passenger)

24x7 claims assistance and support during and after travel

Coverage for trip delays, cancellations, accidents, medical emergencies, and more

Affordable plan options catering to diverse traveller needs

Available APIs

Search API – Fetch available TripSafe plans

Review API – Retrieve coverage details and premium calculations

Booking API – Issue policies instantly

Booking Details API – Access issued policy information

Amendment API – Manage policy modifications

Cancellation API – Process policy cancellations

Embedded API – Issue policies directly using a TripJack Flight ID in a single request

Student API – Long-duration travel insurance for students studying abroad

Annual Multi-Trip (AMT) API – Unlimited travel coverage for 12 months
