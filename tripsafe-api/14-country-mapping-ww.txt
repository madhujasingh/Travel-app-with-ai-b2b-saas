Essentially the full ISO 3166-1 alpha-2 list, confirming the assumption
used elsewhere in this codebase (TripJack flight segments' own
countryCode, Student's manual country input) that standard ISO codes
are correct. A few TripJack-specific quirks/non-standard entries worth
knowing about:
  - Kosovo: "XK" (no official ISO 3166-1 code exists; XK is the common
    unofficial/provisional code used elsewhere too)
  - Ascension Island "AC" and Diego Garcia "DG" listed as separate
    top-level entries (normally sub-divisions of Saint Helena / British
    Indian Ocean Territory in strict ISO 3166-1)
  - Netherlands Antilles "AN" retained despite being officially
    dissolved/deprecated in ISO 3166-1 since 2010
  - "CG" appears twice - once as "Congo", once as "Republic of the
    Congo" - same code, redundant duplicate row in the source, not two
    different countries
  - North Korea is "KP" here - CORRECTS an earlier note in
    10-validation-rules-and-sla.txt, which (following the doc's own
    Section 4 text) listed the blacklisted country as "North Korea(NK)"
    - NK is not a real ISO code; KP is the actual one TripSafe itself
    uses per this catalog.
