4. API REQUEST VALIDATION RULES FOR TRIPSAFE INTEGRATION
======================================================================

--- PAGE 87 ---

Please ensure the following validations are in place:
  - Age Restriction: Searches for travellers above 70 years of age are
    not permitted.
  - Restricted Countries: Searches involving the following blacklisted
    countries are disallowed: Myanmar(MM), Iran(IR), North Korea(NK).
  - Date Range Limit: Coverage duration must not exceed 90 days.
  - Traveller Limit: A maximum of 10 travellers is allowed per search
    request.
  - Cancellation Policy: TripSafe can be cancelled up to 24 hours
    prior to the coverage start date.

  [MAJOR INCONSISTENCY: "Date Range Limit: ... must not exceed 90
  days" is stated here as a blanket rule for "TripSafe Integration" in
  general, but the Search Matrix table (p.89) gives per-journey-type
  duration rules that clearly exceed 90 days in two cases: Standalone
  allows up to 180 days from Start Date, and Student allows up to 735
  days. Only AMT (30/45/60, and per p.83, possibly 90) and Embedded
  One-Way (180 days max, also technically over the stated limit) stay
  within/near it. Treat the 90-day cap in this section as either
  outdated, AMT-specific despite the generic heading, or simply wrong
  - confirm live per journey type using the p.89 matrix instead of
  this blanket rule.]
