3.1 Quotes API - AIRPORT TRANSFERS

Method - POST
API -  /cabs/v2/quotes
Request Body (QuoteRequest)
origin (LocationDto, required): { displayAddress, lat, long, type, address: { … } }
destination (LocationDto, required): same shape as origin.
tripType (required): oneway or return (TripType enum).
journeyType (required): one of airport_transfer | outstations | local | rental | (JourneyType enum).
pickupDate (required): string yyyy-MM-dd HH:mm; must be ≥2 hours in future.
returnDate (optional): yyyy-MM-dd HH:mm; required/validated only when tripType=return and must be ≥30 minutes after pickup.
durationInMinutes (optional)
distanceInKm (optional)
passengers (required): int 1–10.
quoteFilter (internal use, ignored on serialization).

QUOTES API Response Body  - 

Response Body (QuoteRequest)
success: boolean
message: string (e.g., "Successfully fetched quotes") 
data: 
journeyInfo: { journeyType, tripType, pickupDateTime, returnDateTime, journeyLeg, distance, duration, flightDetails }
routeDetails: { isDomestic, origin: LocationDto, destination: LocationDto } 
quotesInfo: array of vehicle groups; each item: 
vehicleType, vehicleCategory, label, modelName, paxCapacity, luggageCapacity, vehicleImages, similarType 
quotes: array of CommonQuoteDto: 
vendorId, vehicleCategoryId, vehicleTypeId, quotationId, quoteChildId 
fareBreakup (onwardFare, backwardFare, totalFare, onwardTax, backwardTax, totalTax)
benefits (list), policies (amendmentPolicy, cancellationPolicy[], inclusions[], exclusions[], baggagePolicy[], waitingTime, termsAndPolicies[], meetAndGreet[]) 
sku, paxCount, luggageCount, model, and optional vehicleCategory/vendorVehicleMapping details.

API -  /cabs/v2/quotes
Request Body (QuoteRequest)
 "journeyType": "outstation". // for outstation transfers.

        "journeyType": "outstation"

        "journeyType": "Local"
